# Security Policy

## Supported Versions

Ombracrux is currently in active R&D. Only the latest experimental release (v0.1.x) receives security patches. 

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues or discussions. Public disclosure before a patch is available puts all users at risk.

Report vulnerabilities, memory leaks, or cryptographic bypasses privately:

*   **Email:** [ombraveil.choice471@passinbox.com](mailto:ombraveil.choice471@passinbox.com)
*   **LinkedIn:** Direct message the [Ombraveil LinkedIn Page](https://www.linkedin.com/company/ombraveil/)

### What to Include

*   A concise description of the vulnerability and impact.
*   The exact Ombracrux version and host OS.
*   Step-by-step reproduction instructions.

## Response Protocol

1.  **Acknowledgment:** We will confirm receipt privately within 72 hours.
2.  **Patching:** If validated, an expedited security patch will be engineered.
3.  **Attribution:** With your explicit consent, you will be formally credited in the release notes for responsible disclosure.
